========================================================

วิธีใช้งานครั้งแรก
--------------------
1. ติดตั้ง Python จาก https://www.python.org/downloads/
   (ตอนติดตั้ง ต้องติ๊กช่อง "Add python.exe to PATH" ด้วย)
2. ดับเบิลคลิกไฟล์ "start.bat"
   ครั้งแรกจะติดตั้งไลบรารีที่จำเป็นให้อัตโนมัติ (ใช้เวลาสักครู่
   ต้องต่อเน็ตครั้งแรกครั้งเดียว) ครั้งต่อไปจะเปิดเร็วทันที

การแปลงเป็นไฟล์ .exe แบบไม่ต้องลง Python (สำหรับแจกเครื่องอื่น)
-------------------------------------------------------------------
ทำครั้งเดียวบนเครื่อง Windows ที่มี Python ติดตั้งอยู่แล้ว:

  ขั้นตอนที่ 1 - สร้างไฟล์ .exe
    ดับเบิลคลิก "build_exe.bat"
    รอสักครู่ จะได้โฟลเดอร์ dist\SD8System\ ซึ่งมี SD8System.exe
    (ทดสอบเปิด .exe ตัวนี้ดูก่อนได้เลย ใช้งานได้แล้วโดยไม่ต้องลง Python)

  ขั้นตอนที่ 2 - สร้างตัวติดตั้ง (Setup.exe) เพื่อแจกจ่าย
    1. ติดตั้งโปรแกรม Inno Setup (ฟรี) จาก https://jrsoftware.org/isdl.php
    2. เปิดไฟล์ "installer.iss" ด้วย Inno Setup Compiler
    3. กด Compile (Ctrl+F9)
    4. ไฟล์ Output\SD8System_Setup.exe คือตัวติดตั้งที่พร้อมแจกจ่าย
       นำไปติดตั้งเครื่องไหนก็ได้ ไม่ต้องลง Python ไม่ต้องลงไลบรารีใด ๆ

  หมายเหตุ: ต้อง build_exe.bat ให้เสร็จก่อน (ขั้นตอนที่ 1) แล้วค่อย
  compile installer.iss (ขั้นตอนที่ 2) เพราะ installer.iss จะไปหยิบไฟล์
  จากโฟลเดอร์ dist\SD8System\ ที่สร้างไว้แล้วมาแพ็ครวมเป็น Setup.exe

การทำงานของโปรแกรม
--------------------
- กรอกข้อมูลในฟอร์ม ระบบจะบันทึกอัตโนมัติทุก 4 วินาที และตอนปิดโปรแกรม
  (ข้อมูลจะไม่หาย แม้ปิดโปรแกรมกะทันหันหรือไฟดับ)
- ปุ่มด้านล่าง 4 ปุ่ม = สร้างเอกสารแต่ละประเภท โดยดึงข้อมูลจากฟอร์ม
  ไปเติมลงไฟล์ Word ทันที (ไม่ต้องเปิด Microsoft Word ค้างไว้)
- ไฟล์ที่สร้างจะถูกบันทึกในโฟลเดอร์ output/ ตั้งชื่อไฟล์อัตโนมัติ
  ตามรูปแบบ [ประเภทเอกสาร]_[ชื่อ]_[วันเวลา].docx
- ทุกครั้งที่กดพิมพ์ ระบบจะบันทึกประวัติลงไฟล์ ฐานข้อมูล.xlsx
  ให้อัตโนมัติ (เปิดดูด้วย Excel ได้ตามปกติ)
- ปุ่ม "เปิดโฟลเดอร์เอกสารที่พิมพ์" เปิดโฟลเดอร์ output ให้ทันที
- ปุ่ม "ล้างข้อมูลทั้งหมด" (มุมขวาบน) ใช้เมื่อจะเริ่มกรอกข้อมูลคนใหม่

โครงสร้างไฟล์ในโปรแกรม
-------------------------
sd8_app/
├── start.bat              <- ดับเบิลคลิกเพื่อเปิดใช้งาน
├── app.py                <- โค้ดหลักของโปรแกรม (หน้าจอ UI)
├── docx_engine.py         <- เครื่องมือเติมข้อมูลลง Word
├── storage.py             <- ระบบบันทึกอัตโนมัติ + ฐานข้อมูล Excel
├── utils.py               <- ฟังก์ชันช่วย (จัดรูปแบบเลขบัตร ฯลฯ)
├── requirements.txt        <- รายชื่อไลบรารีที่ต้องติดตั้ง
├── templates/              <- วางไฟล์ .docx ต้นแบบทั้ง 4 ไฟล์ที่นี่
└── output/                 <- ไฟล์ Word ที่สร้างเสร็จจะอยู่ที่นี่

การแปลงเป็นไฟล์ .exe (ไม่บังคับ)
-----------------------------------
ถ้าต้องการให้เปิดโปรแกรมได้โดยไม่ต้องติดตั้ง Python ก่อน สามารถแปลง
เป็นไฟล์ .exe เดี่ยวได้บนเครื่อง Windows ที่ติดตั้ง Python แล้ว ด้วยคำสั่ง:

    pip install pyinstaller
    pyinstaller --onefile --windowed --name "ระบบสด8" app.py

ไฟล์ .exe จะอยู่ในโฟลเดอร์ dist/ (ต้องคัดลอกโฟลเดอร์ templates
ไปวางข้าง .exe ด้วยเสมอ)
